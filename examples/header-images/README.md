# header-images

The program that draws the README's header images with jitterbug itself, through the public API alone: `docs/images/logo.png`, an animated PNG of an original low-poly beetle turning as it walks on the spot beside the wordmark in the library's 8 x 8 font, drawn at the console's 1x (integer vertices, affine textures, dithering) and shown 3 times larger with hard pixels on a transparent background; `docs/images/beetle.png`, the logo's first frame alone, square, which is also the demo page's favicon; and `docs/images/banner.png`, the lighthouse of [the demo](../demo/README.md) at sunset, from a fixed camera of the banner's own (`dm_scene.shot`), drawn with every artefact on at 1x and with every switch off at 4x and cut diagonally through the middle of the tower.

The test `header_images` (built with `-DJB_EXAMPLES=ON`) draws them again and checks that every file is byte for byte the one checked in, every frame of the logo included, and that `examples/demo/web/index.html` holds `beetle.png` as its favicon. After a deliberate change to the program, the demo or the renderer, draw them again with `cmake --build build --target header_images_regen`, and if `beetle.png` changed, replace the favicon's data URI in `index.html` with what `build/examples/header-images/header-images --favicon-uri docs/images/beetle.png` prints.
