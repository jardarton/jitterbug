jitterbug: first-light

loading

Drawn by jitterbug, a C library that renders like the PlayStation GPU, compiled to WebAssembly: every pixel comes from the same code as the native build (integer arithmetic, and the library's own float maths, which gives the same bits everywhere). Precise vertices only show above 1x; dithering only at 1x; the CLUT cache changes nothing here but the panel's light (the palette is rewritten with jb_palette_write, which clears it). Check mode: ?frames=300 (with &scale=, &precise=, &perspective=, &dither=, &widescreen=, &float=, &clutcache=) draws that many frames as fast as it can and shows their hash.
