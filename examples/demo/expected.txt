# the demo tests (CMakeLists.txt here) and by web/test-module.cjs.
#
# A run is a number of ticks: at each, the script's keys for that tick are
# pressed (the keys of the window and the page: scene.h, dm_key), the frame
# is drawn, and the scene's frame counter moves on by the step unless
# paused. The switch columns are where a run starts.
#

# console's switches. tour flips every switch in turn at known ticks, and
# back: fog (30, 60), dithering (90, 120), perspective-correct (150, 180),
# the CLUT cache (210, 240), widescreen (270, 300), float geometry (330,
# 360), the panel (390, 400), pause (410) with two single steps (415, 420)
# and on again (425), then scale 2x (430), precise vertices (440), 4x
# (450), precise off (455), 3x (460) and 1x (470). The 24-tick runs hide
# the panel at their first tick (H), so that they differ only by their
# switches, and start with one switch flipped each against short (precise
# vertices at 2x, where it shows, against scale2); all3 has every switch
# flipped at 3x. demo-headless requires runs of the same length to draw
# different frames, so a switch that no longer reaches the context fails.
