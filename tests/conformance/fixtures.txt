# What each conformance test plays and must see (FORMAT.md,
# "Fixture tables"). The runner (conformance.c --fixtures fixtures.txt
# --fixture NAME) reads a
# program's whole identity, its reference and its exclusion from its line
# here and from nowhere else; CMakeLists.txt here checks the table and
# makes the tests. One program a line, fields separated by spaces:
#
#   NAME      the program (gpu/NAME), as in tools/conformance-record/programs.txt
#   WHERE     repo: the list is tests/conformance/NAME.jbc and the dump or log
#             third_party/ps1-tests/gpu/NAME; fetched: neither is in the
#             repository (third_party/ps1-tests/README.md says why), both
#             come from the flake's conformance-lists output, passed as the
#             CMake variable JB_CONFORMANCE_FETCHED
#   REFERENCE dump (the console's VRAM) or log (its EXPECT ops)
#   PASSES    the pass of the main loop after which VRAM is compared, the
#             first pass counted (FORMAT.md, "Playing a list"); the two
#             passes after it must not change VRAM
#   EXPECTS   the number of EXPECT ops
#   WORDS     the list's size in 32-bit words
#   CHECKSUM  FNV-1a, 64 bits, of the list's bytes (jbc_checksum)
#   REFSUM    FNV-1a, 64 bits, of the reference file's bytes: the dump's
#             vram.png or the log's psx.log (jbc_file_checksum); the runner
#             refuses any other file in its place before comparing anything
#   EXCLUDE   optional, three fields: the exclusion file, its number of
#             pixels and the FNV-1a of their indices (jbc_exclusion_checksum);
#             the only pixels of any dump not compared, each set described
#             in docs/conformance.md ("Excluded pixels (`lines`)")
#
# The lists are what tools/conformance-record makes from the pinned
# sources, so a re-recording that changes a list changes its line here.
# NAME, WORDS, CHECKSUM, REFERENCE and REFSUM are the recorder's
# fixtures-identity.txt, which the flake check conformance-record compares
# with these lines, fetched programs included.
