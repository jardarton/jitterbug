jitterbug demo

An original scene drawn by jitterbug, a C library that renders like the PlayStation GPU, running here as WebAssembly. Each of the console's artefacts is a switch: flip them and watch.

loading

1x to 4x
the internal resolution. Every frame is still drawn at the console's 1x too.
Precise vertices
above 1x, polygons stop snapping to the 1x pixel grid: no vertex jitter.
Perspective-correct
textures stop swimming across large polygons (the water, near hills): no affine wobble.
Dithering
the console's 4 x 4 pattern on shaded pixels, seen at 1x in the sky and the shading.
CLUT cache
the GPU keeps the last palette it loaded. The sky's cloud bands share one palette row, rewritten before each band with no cache flush: with the cache, every band keeps the first band's colours; without it, each band shows its own.
Widescreen
a 16:9 display, 427 x 240; the view widens with it.
Float geometry
the GTE's fixed-point arithmetic, as on the console, or float.
Fog
the GTE's depth cue towards the haze; without it, the far edge of the world shows.

The sea moves by palette animation alone, and the sun, the lighthouse and the fireflies glow by additive blending. Every pixel comes from the same C as the native build, in integer arithmetic and the library's own float maths, so the frames are the same bits here as anywhere. Check mode: ?frames=240 (with &step=, &scale=, &precise=, &perspective=, &dither=, &widescreen=, &float=, &clutcache=, &fog=, &script=) draws that many frames as fast as it can and shows their hash.
